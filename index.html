01 / WHAT YOU SEE

필요한 신호만
제자리에.

에이전트를 오가며 작업해도 각 한도의 상태를 다시 찾을 필요가 없습니다. 지금 얼마나 썼는지와 언제 돌아오는지를 바로 읽을 수 있습니다.

01

두 에이전트의 한도

Claude와 Codex를 전환해 세션 및 주간 한도, 플랜과 초기화 시각을 확인합니다.

02

속도까지 읽는 막대

시간 마커와 현재 사용률을 비교해 평소보다 빠르게 소진 중인지 알려줍니다.

03

작게 두는 바 모드

두 에이전트의 주요 한도를 한 줄에 놓고, 사용률과 남은 비율을 눌러 바꿉니다.

04

알림과 안전한 업데이트

임계값·초기화를 알리고, 새 버전은 동의한 뒤 검증해 교체합니다. 화면이 닫히면 불필요한 사용량 조회도 줄입니다.

02 / TWO WAYS TO WATCH

자세히 볼 때도,
곁에 둘 때도.

상세 팝업에는 계정, 사용 구간, 로컬 토큰 상세와 설치 버전을 담았습니다. 바 모드는 시계 옆에 두 에이전트의 핵심 수치만 남깁니다. 보고 싶은 방식은 앱이 기억합니다.

  • 01클릭하면 더 깊게사용량 카드를 펼쳐 로컬 기록의 모델별 토큰을 확인합니다.
  • 02열어 둔 채로 가볍게바 모드는 드래그해 원하는 위치에 놓을 수 있습니다.
  • 03한 번 선택하면 그대로보기 모드와 글꼴, 새로고침 주기를 다음 실행에도 유지합니다.

03 / CLEAR ABOUT DATA

무엇을 읽는지
알 수 있게.

사용량을 보여주기 위해 필요한 범위만 다룹니다. 앱은 오픈소스이며, 인증 정보와 로컬 기록을 다루는 방식을 직접 확인할 수 있습니다.

데이터 처리 방식 자세히 보기 ↗
  • Claude 사용량Claude Code의 로그인 정보를 읽고 Anthropic 사용량 API를 조회합니다.
  • Codex 사용량설치된 Codex App Server에 계정과 한도 조회를 위임합니다.
  • 로컬 토큰 상세세션 기록을 기기에서 읽어 계산하며 외부로 보내지 않습니다.
  • 앱 업데이트시작할 때 공개 GitHub 릴리스를 확인하고, 설치에 동의한 경우에만 EXE를 받습니다.

다운로드하고,
트레이에서 시작하세요.

Windows 10/11 x64에서 실행합니다. Claude Code와 Codex에 이미 로그인했다면 별도의 API 키를 입력할 필요가 없습니다.
